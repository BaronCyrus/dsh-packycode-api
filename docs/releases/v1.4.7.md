# v1.4.7：生图模型升级到 GPT Image 2.6

图片生成与编辑的两款高档型号从 GPT Image 2.5 换成 PackyCode 新上线的 GPT Image 2.6 Flare 和 2.6 Sunburst。

- **GPT Image 2.6**：设置里的型号和图片工具都改为 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`。按 OpenAI 文档，2.6 的质量档位和 2.5 相同，仍支持 `xhigh` / `max`；请求格式、尺寸和编辑方式都不变。`gpt-image-2` 不变。
- **原来的 2.5 设置自动沿用**：设置里选过 2.5 Flare 或 2.5 Sunburst 的，会按同名的 2.6 型号读取，质量保持不变，不用重新设置。之前用 2.5 生成的图片照常显示。

验证：558 项测试、两份构建和发布包检查通过，在 Node 22 下也通过。用图片 Key 实测 15 次请求全部成功：2.6 Flare 和 2.6 Sunburst 在 `low`、`xhigh`、`max` 三档下生图和编辑都正常，网关回报的质量与请求一致，编辑后正确改色并保留构图；Sunburst 选 `auto` 时网关回报为 `low`。`max` 档下 Flare 生图约 24 秒，Sunburst 约 96 秒。透明背景、mask 和其它尺寸没有单独验证，新版本尚未在 DSH 桌面端完整验证。

在 DSH 插件管理中更新至 **1.4.7**，然后重新打开 DSH 加载新版。
