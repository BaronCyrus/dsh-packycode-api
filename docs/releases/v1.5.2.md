# v1.5.2：修复流中断未自动重试，并新增折叠高级选项

修复 GPT 等模型高峰期报 `Upstream response stream was interrupted` 时未触发自动重试即中断任务的问题，并在设置页新增默认折叠的「高级选项」卡片，支持自定义重试次数与流空闲超时。

- **流中断自动重试**　网关在已建立的 HTTP 200 SSE 流内转发 `Upstream response stream was interrupted` 时不带 HTTP 状态码，此前会被归为不可重试的 `PI_AI_ERROR`（实际重试 0 次）。现在路由将其识别为可重试的 `TRANSPORT` 传输中断（GPT 网页搜索后端同步覆盖），自动按重试策略重发，且不会停用或误切正常 Key。
- **高级选项（默认折叠）**　在 **设置 → PackyCode → 高级选项** 中可调整插件内置 HTTP 路由的**最大重试次数**（0–100，默认 20）与**流空闲超时**（30–3600 秒，默认 600 秒即 10 分钟），支持一键恢复默认，保存后免重启立即对下一步请求生效。

验证：614 项自动化测试全部通过，覆盖流中断多形态分类、路由及 GPT 搜索重发、配置边界校验、免重启热替换与前端折叠卡片交互；Host 与 Web 构建及发布包预检通过。使用测试 Key（`cc, deepseek-officially` 分组）完成 `scripts/live-check.mjs` 实测：余额与分组读取、`deepseek-flash` / `deepseek-v4-pro` 及四款 Claude 模型问答、失效 Key 轮换、官方自动审查双版本请求及设置页脱敏投影全部通过。
