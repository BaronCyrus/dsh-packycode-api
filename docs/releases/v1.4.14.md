# v1.4.14：更新 GPT-6.2 Sol 和 Astra 模型

PackyCode 模型组现已提供 GPT-6.2 Sol 和 GPT-6.2 Astra。

- **模型替换：** `gpt-6.2-sol` 替代 `gpt-6.1-sol`，`gpt-6.2-astra` 替代 `gpt-6-astra`；移除 `gpt-5.6-sol`，保留 GPT-6.1 Terra。旧会话若仍选中已移除的模型，需要手动重选。
- **路由与能力：** 两款 GPT-6.2 模型通过 Responses API 使用 `codex` 或 `codex-sale` 分组的 Key，支持文本和图片输入，以及 `low` 至 `max` 推理档位。
- **网页搜索和会话标题：** GPT 网页搜索与 GPT-6.2 Astra 的会话标题生成均改用 GPT-6.2 Sol。

验证：584 项测试、Host 和 Web 构建及发布包检查通过。使用插件中已有的 `codex` 分组 Key 实测两款新模型的文本和识图、Astra 会话标题生成；GPT 网页搜索首轮遇到网关流中断，重试成功。

在 DSH 插件管理中更新至 **1.4.14**，然后重新打开 DSH 加载新版。
