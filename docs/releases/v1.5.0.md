# v1.5.0：改进 Claude Code 工具卡片、会话续接和余额显示

Claude Code 对话现在可以查看实际改动和任务进度，输入框也会显示当前模型所用 Key 的余额。

- **文件改动。** 展开 `claude_code` 工具卡片，写入前可查看预览，成功后可查看 CLI 回传的实际增删行。缺少可对应到本次调用的补丁时，卡片会标明「调用预览」。
- **任务清单。** 插件为 `cc` 分组的四款 Claude 模型启用 CLI 原生任务工具。任务按编号合并，展开清单即可查看每项状态。重新打开会话后仍可查看已有记录。
- **长对话。** 输入框旁会显示上下文压缩进度。修复了压缩失败后可能漏掉下一段回复的问题。续接时会核对前文，即使最后一句答复相同，也能识别改过的历史并重建会话。
- **多 Key 余额。** 输入框按所选模型显示预计使用的 Key 余额，运行中跟随本次请求实际选用的 Key。悬停或聚焦可查看 Key 名称和 Claude 使用的通道。

验证：599 项自动化测试通过。官方 Claude Code 2.1.325 连接 PackyCode `cc` 网关，四种 Claude 模型选择的 32 项验收全部通过，89 次请求均返回 HTTP 200，客户端异常和反滥用拒绝均为 0。四款模型都完成了 3 项原生任务，Sonnet 5.5 High 单独复测也通过。本机 DSH 桌面复测中，Sonnet 5.5 的会话记录显示任务完成 3/3，可用库存为 33。文件补丁另在官方 CLI 2.1.259、2.1.295 和 2.1.325 上通过本机隔离验证。

在 DSH 插件管理中更新至 **1.5.0**，然后重新打开 DSH 加载新版。
