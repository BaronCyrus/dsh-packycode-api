# v1.3.2：新增 GPT-5.6 Sol，余额只按 Key 显示

新增 GPT-5.6 Sol 模型；设置页去掉对话和图片两处的余额合计，余额只按 Key 显示。

- **GPT-5.6 Sol**：新增 `gpt-5.6-sol`，与 GPT-6.1 Sol 走同一条 Responses 路由，可带图，上下文 1,050,000、输出 128,000。推理档位为 `low` / `medium` / `high` / `xhigh` / `max`，不能关闭：官方虽支持 `none`，但经 PackyCode 实测仍按 `medium` 推理。需要 `codex` 或 `codex-sale` 分组；会话标题和 GPT-6 Astra 一样交给 GPT-6.1 Sol 生成。
- **余额显示**：「账户与 Key」和图片卡片顶部的合计剩余、合计已用、合计额度已移除。每个 Key 仍显示自己的剩余、已用、额度，以及读取失败或沿用上次余额的提示。
- **说明更新**：README 写明 API Key 只能读到自己的额度，账号总余额请在 PackyCode 控制台查看。

验证：392 项测试、两份构建和发布包检查通过。实测 GPT-5.6 Sol 的五个推理档位都按所选档位发送并正常回答；全部十个模型、Key 轮换与设置页接口的实测检查均正常。设置页改动由构建产物的渲染测试覆盖，未在 DSH 桌面端实机查看。未重启 DSH。

在 DSH 插件管理中更新至 **1.3.2**，然后重新打开 DSH 加载新版。
