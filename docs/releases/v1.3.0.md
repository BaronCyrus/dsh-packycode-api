# v1.3.0：Claude 插件内直连与工具兼容修复

Claude 三个模型改为插件内直接调用，移除本机 CLI 依赖，并修复原生工具调用、工作目录提示和流处理问题。

- **原生对话**：Opus、Sonnet、Haiku 通过 HTTP Messages 调用，使用 DSH 的工具、权限、计划模式、图片附件和完整会话历史；Claude 会话标题也直接通过 HTTP 生成。
- **移除旧 CLI**：删除运行器、安装检测、委派工具、本机 MCP 桥及对应设置界面。无需安装或登录 Claude Code；此前保存的图片仍可查看。
- **工具兼容**：修复模型调用 `Bash`、宿主只认识 `bash` 时反复报未知工具的问题。仅还原本轮实际提供的工具名称，不扩大工具权限，不改写参数。
- **工作目录**：从可信会话数据读取目录，用独立 JSON 字符串区分真实路径与句末标点，避免把 `OtherWorld` 误写成 `OtherWorld.`；保留合法末尾点、Windows 盘符、UNC、空格和反斜杠，优先使用相对路径或 `workdir`。
- **流与错误处理**：修复响应已结束却继续等待、跨分片 CRLF 解析及思考签名回放；客户端策略拒绝与 Key 失效分开处理。特定工具上下文异常只允许在流开始前原样重发一次，网关的分组和客户端政策仍然适用。
- **保留既有修复**：包含 1.2.10 的 OpenAI 上游错误分类、1.2.11 的 Gemini 工具续聊签名处理，以及 GitHub Release 附件交接修复。

验证：395 项测试、两份构建和发布包检查通过。三模型的文本、工具回传、图片输入和中文标题共 12 项真实网关检查全部成功（15 次模型请求，无 403、429 或流错误）；全模型路由、Key 轮换与设置页接口检查通过。工作目录修复另经 Windows 路径、PowerShell 请求和实际工具参数回归验证；工具返回采用模拟数据，未进行 Windows 桌面实机验收。短期实测不代表长期可靠性保证。

在 DSH 插件管理中更新至 **1.3.0**，然后重新打开 DSH 加载新版。
