# v1.5.1：Gemini 对话标题统一由 3.8 Flash 生成

Gemini 4 Carbon、Gemini 4 Argon 和 Gemini 3.8 Flash 会话都使用 `gemini-3.8-flash` 生成标题。

- **会话标题**　首次命名和后续刷新都需要一把能调用 Flash 的 PackyCode 对话 Key。
- **对话正文**　选择 Carbon 或 Argon 时，该模型继续负责正文回复。

验证：602 项自动化测试全部通过，覆盖三款 Gemini 模型的首次命名、标题刷新及普通对话。Host 和 Web 构建及发布包预检通过。实测确认 Carbon 的标题请求发往 `gemini-3.8-flash`。测试 Key 仅有 `cc` 分组，网关返回 `503 model_not_found`，本次未取得在线标题。

在 DSH 插件管理中更新至 **1.5.1**，然后重新打开 DSH 加载新版。
