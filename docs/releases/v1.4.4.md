# v1.4.4：新增 DeepSeek V4 Pro，移除已停服的 Gemini 4 Argon

模型列表新增 DeepSeek V4 Pro，同时移除 PackyCode 已停止提供的 Gemini 4 Argon。

- **DeepSeek V4 Pro**：`deepseek-v4-pro` 与 DeepSeek Flash 一样走 Responses 协议，1M 上下文，最多输出 384K；推理可关，另有 `low` / `high` / `max` 三档。需要 Key 的分组包含 `deepseek-officially` 或 `deepseek-sale`。在模型选择器里排在 Flash 之后，设置页「显示的模型」里也能勾选。
- **V4 Pro 只收文字**：按 DeepSeek 官方文档，只有 Flash 能看图。PackyCode 网关收到发给 V4 Pro 的图片不会报错，而是直接丢掉，模型只能对着一张没收到的图猜。所以插件声明它只收文字：DSH 不让给它附图；会话里已有的图片（比如从 Flash 切过来的会话）会换成一行「图片已省略」的说明再发送。要看图请用 Flash。
- **V4 Pro 的会话标题交给 Flash**：Flash 便宜得多，能用 V4 Pro 的分组都能用 Flash。
- **Gemini 4 Argon 下线**：PackyCode 自 2026-10-27 起不再提供 `gemini-4-argon`，网关拒绝这个模型，公开模型列表里也没有了，插件已从目录中移除。还设成 Argon 的会话会报 `pi-ai provider "packycode" has no configured model "gemini-4-argon"`，在模型选择器里换一个模型即可。Gemini 3.8 Flash 不受影响。

验证：536 项测试、两份构建和发布包检查通过。直连网关实测 V4 Pro：关闭推理及 `low`、`high`、`max` 都按原样生效，输出上限与 Flash 相同；工具没写 `strict` 时，它和 Flash 一样不会乱填可选参数。通过插件实测：四个档位都正常回答；带工具调用时在 `high`、关闭推理和 `max` 下都能续接回 `ok`；会话标题由 Flash 生成；带图片的会话没有把图片发出去，模型直接说明看不到图片。全模型实测中十一个模型都正常回答。新版本尚未在 DSH 桌面端验证。

在 DSH 插件管理中更新至 **1.4.4**，然后重新打开 DSH 加载新版。
