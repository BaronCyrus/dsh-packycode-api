# v1.4.2：新增 GPT-6.1 Terra

新增 OpenAI 的 GPT-6.1 Terra（`gpt-6.1-terra`）：价格是 GPT-6.1 Sol 的一半，也是唯一可以关闭推理的 GPT 模型。

- **新模型**：GPT-6.1 Terra 和 GPT-6.1 Sol 走同一条 Responses 通道，支持文字和图片输入，上下文 1,050,000 token，单次最多输出 128,000 token，数据来自 OpenAI 官方模型页。模型选择器里它排在 GPT-6.1 Sol 后面。Key 需要在 `codex` 或 `codex-sale` 分组，设置页「账户与 Key」的 GPT 一栏会显示每个 Key 能否使用。
- **可以关闭推理**：档位有关闭和 `low` / `medium` / `high` / `xhigh` / `max`。关闭时发送 OpenAI 文档列出的 `none`，经 PackyCode 实测原样生效，不产生推理 token。GPT-5.6 Sol 的文档也列出 `none`，但经 PackyCode 会按 `medium` 回答，GPT-6.1 Sol 则直接拒绝，所以这两个模型仍不能关。
- **会话标题**：Terra 比 GPT-6.1 Sol 便宜，所以 Terra 会话的标题由它自己生成；GPT-6 Astra 和 GPT-5.6 Sol 的标题仍交给 GPT-6.1 Sol。

验证：536 项测试、两份构建和发布包检查通过。用 `codex` 分组的 Key 实测：直连网关时六个档位都按原值生效，关闭推理时推理 token 为 0；经插件路由，各档位、识图（红、蓝两张图）和工具调用续接（`high` 与关闭推理各一次）全部通过；全模型实测中 11 个模型都正常回答，Key 轮换、失效 Key 识别、自动审查和设置页收到的数据都没有变化。新版本尚未在 DSH 桌面端验证。

在 DSH 插件管理中更新至 **1.4.2**，然后重新打开 DSH 加载新版。
