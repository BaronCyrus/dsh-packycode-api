# v1.2.9：修复清空全部 Key 报错

修复点击「清空全部」报错「读取 PackyCode 状态失败: PackyCode request failed」、Key 没有被删除的问题。

- **原因**：清空后插件写入了 `activeId: undefined`，DSH 的凭据服务只接受纯 JSON 值，于是拒绝了整次写入。
- **同时修复**：单独删除最后一个对话 Key 或图片 Key 时的同样报错；只有一个 Key 且额度用尽或被拒时，它现在会被正确标记为停用（此前只在日志中记录，设置页仍显示可用）。
- **报错更清楚**：凭据写入失败时显示具体原因；修改 Key 失败的提示改为「更新 Key 失败」，不再显示为「读取 PackyCode 状态失败」。

验证：444 项测试、两份构建和发布包检查通过。测试中的凭据存储改为与 DSH 0.2.0-rc.2 相同的「只接受 JSON」规则，修复前 4 个现有测试会复现同样的错误。本轮未调用网关，未重启 DSH。

在 DSH 插件管理中更新至 **1.2.9**，然后重新打开 DSH 加载新版。
