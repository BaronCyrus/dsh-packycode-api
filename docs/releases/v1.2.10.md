# v1.2.10：GPT 偶发上游错误改为自动重试

修复 Codex 分组的 gpt-6.1-sol 偶尔直接报「本轮运行失败 An error occurred while processing your request…」（PI_AI_ERROR）的问题：这类上游临时错误现在会自动重试。

- **原因**：这是 OpenAI 上游的临时服务错误（503 `server_error`）。它出现在网关已经开始返回数据流之后，不带 HTTP 状态码，DSH 无法识别，归为不会重试的 PI_AI_ERROR；同样的错误如果以 HTTP 500 返回，本来就会自动重试。
- **修复**：插件把这类上游 `server_error` 识别为服务端错误，交给已有的重试策略（最多 20 次，逐步加长间隔）自动重发。错误发生在任何输出之前，重试不会丢内容；Key 不会被停用或切换。
- **仍然失败时**：只有所有重试都失败才会显示原始报错，最长约 3 分钟，与 HTTP 500 的处理一致。

验证：457 项测试、两份构建和发布包检查通过；新增 5 项测试，其中 3 项在修复前复现了同样的 PI_AI_ERROR。实测 Codex 分组 gpt-6.1-sol（high 推理）：修复前 14 次请求中有 2 次出现该错误，原样重发都成功了；修复后 20 次请求中有 2 次出现，都被识别为可重试的服务端错误，报错原文不变。其余模型、Key 轮换和设置页接口的实测检查均正常。未重启 DSH。
