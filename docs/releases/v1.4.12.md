# v1.4.12：新增 Gemini 4 Carbon

PackyCode 模型列表新增 `gemini-4-carbon`，沿用 Gemini 原生协议，支持文字、图片与工具调用。

- **新增模型选择**：显示名为 Gemini 4 Carbon，排在 Gemini 4 Argon 前；已有模型偏好会默认选中新模型，设置页的 Gemini 覆盖提示也包含 Carbon。
- **按官方规格配置**：1,048,576 token 上下文、65,536 token 单次流式输出，提供 `low` / `medium` / `high` 三档思考；未指定档位时使用 `medium`。
- **沿用原生工具续聊**：通过 `/v1beta` 发送请求，复用现有思考档位和思维签名兼容处理；Key 可用性仍根据网关返回的实时模型列表与分组信息判断。

验证：581 项测试、两份构建和发布包检查通过。使用插件已保存的 Key，通过构建后的路由实测 Carbon：`high` 档文字正常回复，`low` 档正确识别红、蓝图片，`medium` 档工具调用与 DSH 持久化续聊成功，续聊一次请求即返回 HTTP 200。桌面应用中的模型选择器与对话流程尚未实测；本次未重测其它模型。

在 DSH 插件管理中更新至 **1.4.12**，然后重新打开 DSH 加载新版。
