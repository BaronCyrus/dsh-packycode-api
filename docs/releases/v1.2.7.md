# v1.2.7：图片 Key 重命名与注册邀请

图片 Key 支持重命名，模型选择器旁的额度悬浮与生图 Key 统一，并在设置页加入注册邀请。

- **图片 Key 重命名**：设置 → PackyCode → 图片生成与编辑中的图片 Key 也可以「重命名」，与对话 Key 共用同一个改名表单：回车或「保存」生效，Esc 或「取消」保留原名。
- **统一的额度悬浮**：模型选择器旁的 PackyCode 额度与生图 Key 额度使用同一个组件：带问号光标，悬浮或聚焦时显示同样的详情（哪种额度、当前 Key、账户名、剩余/已用/总额度、读取时间或读取失败）。
- **注册邀请**：还没有存任何对话 Key 时，「账户与 Key」在空状态说明下显示 PackyCode 注册邀请链接，在系统浏览器中打开；存入 Key 后不再显示。
- **README：安装要带版本号**：插件页的安装提示显示 npm 最新版，但 DSH 自带的 pnpm 11 只装发布满 24 小时的版本。安装说明现在统一写成 `dsh-packycode-api@<版本号>`，FAQ 说明了旧版首次安装后设置页报 HTTP 405 的原因和处理办法。

验证：422 项测试、两份构建和发布包检查通过。在隔离的 DSH 0.2.0-rc.2 环境中复现了首次安装的 405：只填包名会装上 1.1.5 并报 405，填 `dsh-packycode-api@1.2.6` 则立即正常。浏览器回放确认邀请链接在深浅色主题下显示正确，存有 Key 时不显示。本轮未重启 DSH，未发起付费请求或实时网关调用。

在 DSH 插件管理中更新至 **1.2.7**，然后重新打开 DSH 加载新版。
