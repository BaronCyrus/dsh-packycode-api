# v1.2.8：诊断信息与 Claude 标题修复

新增诊断信息卡片，并修复 Claude 会话标题变成英文 JSON 的问题。

- **诊断信息**：设置 → PackyCode → 诊断信息，选择出问题的会话（最近 20 个），生成后复制发给插件作者。内容只有设置和数字：插件版本、会话 id 与创建时间、每个 Key 的序号与分组、每次请求的模型/推理档位/输出上限、最近若干步的 token 用量与结束原因，以及重试和失败的错误码（错误信息已脱敏并截短）。不含对话内容、文件路径、Key 备注名和 Key。
- **Claude 会话标题**：Claude 会话的标题由 `claude-haiku-5-5` 在 Claude Code CLI 中生成，「在吗」这类短消息曾被起成 `{"title": "Casual greeting check-in"}` 这样的英文 JSON。现在提示词末尾会重申「只回纯文本标题、用消息原文的语言」，只读取 CLI 最后一个文本块，并剥掉 JSON、代码块、「Title:」前缀和引号；多行回复或「对话标题」这类占位词不作为标题，DSH 保留按首条消息生成的默认标题。
- README 增加用诊断信息反馈问题的说明。

验证：437 项测试、两份构建和发布包检查通过；浏览器回放验证了诊断卡片的会话选择、生成和复制（剪贴板被拒时全选文本）。用 DSH 0.2.0-rc.2 原样的标题请求经 CLI 实测：修复前「在吗」得到 `Greeting Check-In` 和 `{"title": "Session greeting check"}`，修复后 10 次标题均为纯文本，中文消息得到中文标题。

在 DSH 插件管理中更新至 **1.2.8**，然后重新打开 DSH 加载新版。
