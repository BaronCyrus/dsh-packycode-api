# v1.3.5：Claude Code CLI 版本过低可一键更新，cc 分组固定走 CLI

本机 Claude Code CLI 太旧时，插件会在发请求前说清原因，并可在设置里一键更新；`cc` 分组的 Claude 请求固定走官方 CLI。

- **CLI 版本过低一键更新**：插件需要 Claude Code 2.1.259 或更新版本。以前 CLI 过旧时，每次 Claude 请求都会报「版本过旧」，设置里却仍显示已安装。现在插件在启动 CLI 前就检查版本，说明需要的版本。**设置 → PackyCode → Claude Code CLI** 会标出「版本过低」，点「更新 Claude Code CLI」即可：官方安装器装的 CLI 执行 `claude update`，npm 装的用 npm 更新。只有点这个按钮时才会改动你的 Claude Code。
- **修复 npm 12 装出无法运行的 CLI**：npm 12 默认不运行安装脚本，而 Claude Code 要靠安装脚本放入程序本体，所以「一键安装」装好的 CLI 只会提示 `claude native binary not installed`。现在安装和更新都会放行 Claude Code 的安装脚本；卡片和报错里给出的终端命令也已改好。npm 10、11 同样适用。
- **cc 分组固定走 CLI**：去掉了 Claude 通道的「按分组 / 始终用 CLI / 始终用 HTTP」选项。`cc` 分组的 Key 一律经官方 Claude Code CLI 发出，其它分组走插件内 HTTP；以前保存的选项会被忽略。
- **发布节奏**：新版本直接发布到 npm 的 `latest`。从 1.3.2 或更早版本升级时，请在插件页填写 `dsh-packycode-api@1.3.5` 安装，不要点旧版设置页里的「更新插件」。
- **其它**：两份 README 末尾加入作者的微信和支付宝赞赏码。

验证：458 项测试、两份构建和发布包检查通过。在临时目录里用真实 CLI 跑插件的更新流程：官方安装器装的 2.1.223 经 `claude update`、npm 装的 2.1.223 经 npm 12，都升到了 2.1.303。用 `cc` Key 实测：2.1.223 在发请求前就被拦下并给出说明；经 Claude Code CLI 2.1.295 对 Opus、Sonnet、Haiku 各做文本、工具调用、图片、会话标题和计划模式检查，15 项全部通过；升级后的 2.1.303 上 Haiku 5 项也全部通过；十个模型、Key 轮换与设置页接口的实测均正常。设置卡片由界面测试覆盖。

在 DSH 插件管理中更新至 **1.3.5**，然后重新打开 DSH 加载新版。
